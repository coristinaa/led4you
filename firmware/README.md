# LED4YOU firmware (ESP32-C3)

Latest version: **v16** (see `latest.json`)

| File | Use |
|---|---|
| `LED4YOU_v16_ESP32-C3_update.bin` | Update a board that already runs LED4YOU/WLED: Config → Security & Updates → Manual upload |
| `LED4YOU_v16_ESP32-C3_completo.bin` | First install over USB: flash at address **0x0** (full 4 MB image) |

Source code: branch [`firmware`](https://github.com/coristinaa/led4you/tree/firmware) (based on WLED 16.0.1, EUPL-1.2).

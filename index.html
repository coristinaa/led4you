Install LED4YOU on a new board

Connect the ESP32-C3 or ESP32 board to this computer with a USB cable. The right file for the chip is chosen by itself.

If the board is not found, hold its BOOT button while you plug in the cable. Choose "Erase" for a new board.

Installing needs Chrome or Edge on a computer (Windows, Mac or Linux). Phones cannot do it.

What the lights report
DMX output
Sends the colours to DMX lights (spotlights, LED bars, PAR cans…) through an RS-485 module (for example a MAX485, or the DMX terminal of the LED4YOU base board). Each DMX light follows one LED: light 1 the colour of the first LED you choose, light 2 the next one, and so on.
